# 豆屿 · 图片转拼豆小程序

微信原生小程序首版，附带使用同一套算法和图纸绘制代码的浏览器预览。图片在设备本地处理，无后端、无登录、无运行时第三方依赖。

## 快速试用浏览器预览

在此目录打开终端：

```sh
npm run preview
```

打开 <http://127.0.0.1:4173/preview/>。需要 Node.js 18 或以上，不需要 `npm install`。也可直接用浏览器打开 `preview/index.html`，但推荐本地服务，以便作品存储使用稳定的来源地址。

默认示例是项目原创绘制的「林间小兔」。支持导入 JPG / PNG / WebP、生成、编辑、导出和作品保存。浏览器作品存于 localStorage，与微信小程序作品库互相独立。预览是验证算法和交互的配套工具，不能替代微信真机测试。

## 在微信开发者工具运行

1. 安装并打开微信开发者工具，选择「导入项目」。
2. 导入整个 `douyu-miniprogram` 目录（这一层含 `project.config.json`），项目会自动使用 `miniprogram/` 作为小程序根目录。
3. 将 `project.config.json` 中的 `appid: "touristappid"` 换成自己的小程序 AppID；仅本地查看时也可按开发者工具允许的方式使用测试号。游客模式不保证全部能力可用。
4. 选择「不使用云服务」，编译即可。项目使用原生 JavaScript / WXML / WXSS，不需要 npm 构建或 TypeScript 编译。
5. 基础库配置为 3.7.0。使用支持 Canvas 2D、`wx.chooseMedia` 的当前微信客户端进行真机预览，逐项完成 `docs/ACCEPTANCE.md`。
6. 发布前在小程序后台按实际调用填写《用户隐私保护指引》，说明选择照片/相机仅用于本地制图。代码调用 `wx.requirePrivacyAuthorize`（平台提供时）后才打开选图界面。

当前环境没有微信开发者工具，**未完成 WXML 真正编译、开发者工具模拟器或 iOS / Android 真机验收**。本次已完成 JS/JSON 检查、WXML 事件绑定静态检查、核心算法与原生页面逻辑的自动化测试，以及浏览器实际生成与导出验证。真实 AppID、后台隐私配置与真机验收完成后才能提交发布。

## 首版功能

- 图片导入：微信相册/拍照；保留原文件透明信息；20 MB / 4000 万像素输入上限。
- 构图：完整显示或裁剪铺满，90° 旋转，1–3 倍放大与水平/垂直偏移。
- 尺寸：横向 16–128 颗，常用 32 / 48 / 64 / 96 / 128；原图、1:1、4:3、3:4 比例。高度自动计算且限制为 128；超长图片在完整显示模式下留空边，在裁剪模式下裁切，不拉伸。
- 配色：MARD 221 参考色卡；自动匹配使用 220 个色号，H1 仅供手动选择。8 / 12 / 16 / 24 / 36 / 48 / 96 / 220 色上限。
- 采样：照片区域平均、像素画最近邻；透明区域留空或铺白；可选轻度杂点清理。
- 预览：拼豆圆孔效果、色号网格、裁剪原图；缩放、拖动；微信双指缩放，浏览器滚轮缩放。
- 编辑：画笔、擦除、取色、整色替换；60 步撤销/重做；快速拖动时自动补齐中间格子。
- 清单：实时色号数量与总豆数；微信复制文字清单，浏览器导出 UTF-8 BOM CSV。
- 导出：效果 PNG；按最多 48×48 格分块的施工 PNG，带绝对行列坐标、每格色号、五格辅助线；附独立分页用豆清单。空格以点标记，不计入豆数。
- 保存：微信以独立 JSON 文件保存网格与完整色卡快照，用缓存保存索引；覆盖保存时先写新文件，索引成功后清理旧文件。浏览器存于 localStorage，额外支持 JSON 工程备份与恢复。
- 作品库：重开、继续编辑、重命名、删除。

保存的工程保留网格、色卡和参数，**不保留原始照片**。重开可继续编辑格子和导出；要重新裁剪或转换原图，需再次选择图片。生成上限只约束自动配色，手动加色后可能超过上限。

## 操作建议

1. 点击「导入你的图片」，或先使用小兔示例。
2. 选择豆数和颜色上限，需要裁剪时打开「构图与细节调整」。
3. 点击「生成我的拼豆图纸」。参数修改不会直接覆盖已编辑的图纸，必须重新生成。
4. 图纸页选择画笔颜色，放大后修改；「替色」工具会把点到的整种颜色替换成当前画笔色。
5. 保存作品；导出时选择效果图或施工图。微信会打开图片预览，左右滑动查看，长按单张图片保存到相册。

## 代码结构

```text
project.config.json          微信开发者工具入口
miniprogram/
  pages/studio/              制作、编辑、作品库及手机样式
  core/engine.js             Lab 色差、透明采样、限色、编辑、计数、校验
  core/render.js             原图变换、预览、分块施工图与清单绘制
  core/demo.js               原创示例图（代码绘制）
  data/palette.js            固定版本 MARD 221 色卡及原始许可证
  utils/storage.js           微信本地作品存储
preview/                    独立浏览器预览，与微信共用 core 和 data
tests/                      核心算法、导出、微信页面逻辑和存储测试
third-party/                原始色卡 CSV、许可证
docs/                       验收记录、隐私说明、技术设计
```

# 本地数据说明与上线配置参考

用户选择的照片仅用于设备上的 Canvas 解码、配色和图纸生成。此版本没有上传、登录、埋点、广告 SDK 或服务端接口。

选择相册或拍照时使用 `wx.chooseMedia`。若平台提供，调用前执行 `wx.requirePrivacyAuthorize`。拒绝或取消选择不会上传或保存照片，作品仍可使用本地示例体验。

用户主动保存作品时，网格、色卡、标题和参数存入小程序的本地文件与缓存；不会保存原始照片。用户可在作品库删除作品。清理小程序本地数据会删除全部本地作品。

用户主动导出时会生成本地临时 PNG，并在微信图片预览中展示。只有用户长按选择保存，图片才由微信写入相册。用户主动点击复制清单时写入剪贴板。

发布负责人需要在微信后台按实际能力配置《用户隐私保护指引》，填写自己的主体、联系信息及用途，并在真机上确认授权弹窗、拒绝路径、相册/相机调用、导出长按保存均正常。本文件只是与当前代码对应的事实说明，不代替后台配置。
